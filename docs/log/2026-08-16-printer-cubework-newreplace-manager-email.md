# 2026-08-16 (seventh pass) — CW Email Request, Printer tab: Cubework + New/Replace Printer Request, new checkbox + required Manager Email

Added a third Printer checkbox, `era_pr_newreplace` ("New/Replace Printer Request", a new checkbox distinct from "Setup New Printer" — both still needed). When ticked alongside Cubework, the entry strips to the top-level Location field ("Location Features" = the existing page-level Location search, no new field), Office or Warehouse, Printer Model, the shared "Describe the issue" box, and a new required Manager Email field (mirrors Phone tab's "Report to Manager"); Email/Unit/Phone/Tenant Name/Company Name/Notes all hide. This combo takes precedence over both Setup New Printer and Troubleshoot if more than one is ticked alongside Cubework — `eraApplyPrinterCubeworkVisibility()` was extended with this explicit precedence. Server-side, `buildGeneric()` gained `isCubeworkNewReplace` with a required-fields branch (only Printer Model + Office/Warehouse + Manager Email), a Manager Email format check, a `Report to Manager:` body line, and a subject-line fallback fix (`companyName || extra || cfg.fieldLabel`) since Company Name is blank for this combo and would otherwise produce a subject ending in "- ". Attachment stays unrequired (Printer has no unconditional attachment rule anywhere).

Files: `public/index.html`, `functions/emailRequest.js`
