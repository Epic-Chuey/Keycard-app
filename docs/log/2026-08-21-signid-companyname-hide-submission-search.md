# 2026-08-21: Tenant Company Name hidden, Signature/ID spacing, Submission search + collapsible colorized rows

Follow-up to the same day's [Date fields/Notes reorder/auto E-Signature/remote sync pass](2026-08-21-signid-date-notes-autoesign.md). All client-only (`public/index.html`'s CW Email Request embed `<script>`), no `functions/`/`src/app.js` change.

- **Tenant Company Name hidden:** `.era-k-companyName`'s wrapper div in each keycard entry now carries `era-field-hidden`; Tenant First and Last Name's own wrapper spans the full `era-row2` width (`grid-column:1 / -1`) to fill the gap. Since `companyName` is still a required field server-side (`functions/emailRequest.js`'s `requiredBase`) and drives the email subject/company-display text, `j()`'s entry template now mirrors Tenant Name's value into the hidden Tenant Company Name input live on every `input` event — staff never see or type a second value, and every downstream check/line that reads `companyName` keeps working unchanged.
- **Spacing:** added `margin-bottom:16px` to the Date Issued/Date Returned `era-row2` so it's visually separated from the "Signature / ID" label below it instead of touching it.
- **Submission (Keycard Submission History) — search, per-row collapse, color:**
  - Added a search box (`#era_k_historySearch`) above the list, filtering the currently-selected Pending/Complete tab's rows by location text and each entry's summary line (company/tenant/keycard #) — case-insensitive substring match, re-applied on every keystroke via `eraRenderKeycardHistory()`.
  - Each submission row is now its own `<details class="era-k-history-row">` (previously a plain always-expanded `<div>`) — click the summary to collapse/expand just that one. Its own `<summary>` shows a status chip (colored pill), the location, and a card-count badge; the body (entry lines, Photo ID line, View/Edit/Mark/Delete buttons) is inside the collapsible content.
  - Row color: pending rows get an amber left border + tint (`#f59e0b`/`#fffbeb`), complete rows get green (`#16a34a`/`#f0fdf4`) — same colors used for the status chip.
  - **Expand all** / **Collapse all** buttons next to the search box operate on every currently-rendered row (`.era-k-history-row`) by setting its `.open` property directly.
  - **State survives the 3s auto-refresh:** `eraRenderKeycardHistory()` (already on a `setInterval(…, 3000)` polling the Firestore cache) rebuilds `#era_k_historyList`'s `innerHTML` from scratch every tick — naively this would reset every row back to expanded on each refresh. Fixed with a module-scoped `eraKeycardHistoryCollapsedIds` `Set`, kept in sync via each row's native `toggle` event (fires on manual click AND on the Expand/Collapse-all buttons' scripted `.open` assignment) and consulted when building each row's `open` attribute on the next render. Search text (`eraKeycardHistorySearchQuery`) is similarly module-scoped so typing isn't wiped by the same interval.
