# 2026-08-10: Load-time pass — lazy-loaded export libs, background video removed, src/ + build step introduced

Four load-time fixes made the same day: (1) `xlsx`/`html2canvas`/`jsPDF`/`pdf.js` (~1-2MB combined) now lazy-load via `ensureXLSX`/`ensureHtml2Canvas`/`ensureJsPDF`/`ensurePdfJs` on first actual use instead of blocking `<script>` tags on every page load; (2) the persistent `#roadmapBgVideo` YouTube background-music iframe (and its Access-tab "Show YouTube video" setting) was removed outright per Huy's request, since it started loading/buffering before sign-in regardless of the per-user toggle; (3) `public/app.js` became a generated build artifact — the real, maintained source moved to `src/app.js`, and `npm run build` (esbuild `--minify --format=esm --target=es2020`, no bundling) regenerates `public/app.js` (560KB → ~217KB) with a `// GENERATED FILE` banner; forgetting to build before deploy ships stale code (pitfall #11); (4) a render-blocking Google Fonts `<link rel="stylesheet">` in `<head>` was found (via a DevTools screenshot showing LCP 44.86s, with CLS/INP both fine) to be stalling first paint entirely — fixed with the standard preload + `media="print" onload="this.media='all'"` loadCSS pattern (pitfall #12). None of this was verified against the live site — the session had no browser/network access.

Files: `src/app.js`, `public/app.js`, `public/index.html`, `package.json`
