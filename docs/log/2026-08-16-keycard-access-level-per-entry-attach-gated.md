# 2026-08-16 (second pass) — CW Email Request, Keycard tab: Access Level moved into each entry, Attachments gated to Activate

Access Level (previously one shared checkbox group for the whole request) moved into each keycard entry via `eraCreateKeycardEntry()`, positioned right after Keycard Number so it sits above Notes for Activate/De-activate/Transfer and above "Describe the issue" for Troubleshoot — so different keycards in one request can now carry different access levels. The old shared `era_k_access_*` checkboxes/`era_k_accessCustom` input are removed; `eraKeycardAccessValue()` now reads per-entry, and `eraCollectFields()` moved `accessValue` from a top-level field to a per-entry one. The Attachments picker (previously always shown) is now tagged `.era-k-attach-fields` and only shown once at least one entry's action is Activate, via new `eraUpdateKeycardAttachVisibility()` (hidden for De-activate/Troubleshoot/Transfer-only requests). Server-side, `buildKeycard()`'s blanket "attach the signed form" requirement now only applies when at least one entry's action is Activate, and `accessValue` prints per-entry (`Access: ...` line under each entry's action line) instead of once in `sharedBlock`.

Files: `public/index.html`, `functions/emailRequest.js`
