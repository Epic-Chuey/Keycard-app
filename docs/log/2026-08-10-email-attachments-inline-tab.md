# 2026-08-10 — Email (Attach.) Inline tab + doPost() cross-origin endpoint

Since iframing the standalone "Cubework Email Request — with Attachments" Apps Script project failed the day before (script.google.com blocks cross-origin framing — [pitfall #10](../pitfalls.md)), this ports that project's HTML/CSS/JS directly into `index.html` (genuinely part of this document, no iframe) and swaps its `google.script.run.submitEmailRequest(payload)` call for a `fetch()` POST straight to that project's `/exec` URL. Required adding `doPost(e)`/`jsonOut()` to that project's own `Code.js` (purely additive — parses the POST body as JSON and calls the existing `submitEmailRequest()`; `doGet()`/the original page are untouched). The cross-origin `fetch()` works with no server-side CORS config because `Content-Type: text/plain;charset=utf-8` keeps it a CORS "simple request" (no preflight `OPTIONS`, which Apps Script can't answer anyway), and Apps Script's own redirect to `script.googleusercontent.com` carries `Access-Control-Allow-Origin: *` as a platform behavior.

Since `app.js` is a module (its own scope), the ported form is a separate classic `<script>` IIFE, bridged only via `window.EMAIL_REQUEST_ATTACHMENTS_URL` so both the embed and the original button share one URL source of truth; every id/class in the ported markup got an `era_`/`era-` prefix scoped under `#emailRequestAttachmentsEmbedView` to avoid collisions. New tab `emailRequestAttachmentsEmbed` ("📎 Email (Attach.) Inline") wired through `MANAGEABLE_TABS`, the Access tab, `HERO_COPY`, and both `renderActionTabs()` guards — no `firestore.rules` change needed (no Firestore collection behind it).

Huy's live test hit `TypeError: Failed to fetch`; reproduced safely (bogus `mode` value, so no real email risk) and found a real 503 from `script.google.com`, consistent with the Apps Script deployment not yet running the new `doPost()` code (needed its own "Manage deployments → New version" step). The original `window.open()` "Email (Attachments)" tab was left untouched throughout as the fallback.
