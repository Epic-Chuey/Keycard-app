# 2026-07-03 — Initial build and launch

Built the original app: syncs Outlook's Helpdesk > Keycard folder into a searchable dashboard, backed by Firestore/Firebase Hosting, installable as a PWA. Chose delegated Graph auth (refresh token, signed in as huy.nguyen@cubework.com) over app-only permissions since delegated Mail.Read for one's own mailbox is self-service (no tenant-admin consent needed). Since emails are free-form (not templated), built a heuristic/regex parser (`functions/parseEmail.js`) rather than a strict-schema one — raw subject/preview is always kept alongside extracted fields so nothing is silently lost. Architecture: Graph API → scheduled Cloud Function (parses + syncs every 15 min, chunked at 400 writes/batch) → Firestore `keycardTickets` → PWA frontend.

Deployment debugging found four root causes in order: (1) the refresh token was issued via device-code (public client) flow but redeemed via `ConfidentialClientApplication` — fixed by using `PublicClientApplication` for both (`functions/graphAuth.js`); (2) the `MS_CLIENT_ID` secret got corrupted twice (a bad doubled paste, then a PowerShell BOM from `Set-Content -Encoding utf8`) — fixed by using `-Encoding ascii`; (3) the code queried `/users/{email}/mailFolders` (app-only shape) instead of `/me/mailFolders` (delegated shape); (4) `Helpdesk` was assumed top-level but is actually nested under Inbox — fixed by looking it up via `/me/mailFolders/inbox/childFolders`. Also, the first sync had no cutoff and tried to pull all ~7,768 historical messages at once, blowing past Firestore's 500-writes-per-batch limit and the function's 60s timeout — fixed by seeding the first run with only the 10 most recent messages and using the newest as the baseline going forward.
