# 2026-08-18: Standup "3. Saved": Issue-tab summary source, auto-expanded rows, feature cleanup

Three changes to Standup's "3. Saved" step in `src/app.js`. (1) "View Short Version," "View Long Version" (the Vertex AI Kuan-brief feature), and "Generate Report then Open Outlook" (the custom date-range ad-hoc summary) were removed outright — their UI, handlers, and supporting functions (`standupKuanBriefCache`, `STANDUP_KUAN_BRIEF_KINDS`, `buildStandupKuanBriefPreviewHtml`, `buildStandupKuanBriefEditFormHtml`, `standupLoadKuanBriefInto`, `parseStandupKuanBriefSummary`, `buildStandupRangeEmailBody`, and the range-input DOM refs) are all gone; `functions/index.js`'s matching Cloud Functions are left in place, untouched. "Export All" is untouched. (2) "Summary for Kuan Goh"'s Cali Issues/Outside Cali Issues fallback text now sources from the Issue tab's own Active issues (via new `standupFetchIssueRegions()`/`standupSaveFallbackIntroText()`), matching the live "2. Report" step's 2026-08-15 switch, replacing the old checklist-based fallback this panel had deliberately kept for historical accuracy — a day that already has its own saved `summaryIntroText` is unaffected. (3) Every saved day's report panel now renders already expanded (`renderStandupSavedList()` is now async and builds every row's Summary+Entries panel up front) instead of requiring a "View report" click; that button was renamed "Hide report" and now just toggles collapse state.
