# 2026-08-15 (fourth pass): CW Email Request — per-mode email signature

Microsoft Graph has no API for a live per-user Outlook signature, and this app's Microsoft sign-in carries no Mail scopes anyway, so each of the six CW Email Request modes now appends a fixed, pre-made signature image (`functions/assets/signatures/{keycard,wifi,printer,phone,app,laptop}.png`) via new `appendSignature()` in `functions/emailRequest.js`. It's attached inline via `cid:` rather than a `data:` URI — Outlook desktop's rendering engine doesn't support base64 `data:` URIs in HTML email — by `sendViaGraph()` as a small inline `fileAttachment`, added on both the small (`/me/sendMail`) and large (draft + upload-session) send paths, and kept out of the byte-size accounting used to choose between them. `buildKeycard()`/`buildWifi()`/`buildGeneric()` all now also return `mode`; the plain-text `SIGNATURE_NOTICE` fallback only matters to the dormant "Open in Outlook" deeplink path. No client-side (`public/index.html`) change was needed.

Files: `functions/emailRequest.js`, `functions/assets/signatures/keycard.png`, `functions/assets/signatures/wifi.png`, `functions/assets/signatures/printer.png`, `functions/assets/signatures/phone.png`, `functions/assets/signatures/app.png`, `functions/assets/signatures/laptop.png`
